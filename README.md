## 🚀 How to Run

### Method 1: Instant Local Preview (Zero Setup)
Simply navigate to `e:\Hemisphere-html\` in your file explorer and **double-click `index.html`**. It will immediately open and run smoothly in Chrome, Edge, Safari, or Firefox!

### Method 2: Live Server in VS Code
1. Open the folder in VS Code.
2. Right-click `index.html` and select **"Open with Live Server"**.

## 🌟 Included Features & Libraries (Loaded via CDN)

- **Native Circular Aperture Masks**: 60fps scroll-driven circular portal reveal on Section 8 (*Events*) and Section 9 (*Destination*) with zero external animation dependencies.
- **Lenis 1.1**: Provides 60fps kinetic inertia smooth scrolling with responsive anchor navigation.
- **Tailwind CSS (CDN)**: Configured with Hemisphere's exact luxury brand color tokens and typography hierarchy.
- **Lucide Icons (CDN)**: Lightweight SVG iconography throughout navigation, booking fields, and buttons.
- **Vanilla JavaScript State Engine**:
  - **Fullscreen Preloader**: 0% → 100% counter with animated gold progress bar.
  - **Hero Slider**: Auto-advancing property photography every 3.2s with next/prev buttons and dynamic location tags.
  - **Universal Booking Widget**: Destination dropdown, native calendar date pickers, Adults/Rooms increment/decrement counter, and simulated search feedback.
  - **Portfolio Filter Tabs**: Real-time filtering for *All Stays*, *Coastal Sanctuaries*, and *Waterfront & City*.
  - **Header Scroll Detection**: Switches from transparent to frosted milk-white glass on scroll.
  - **Mobile Drawer Menu**: Fullscreen slide-over with accordion navigation for Stays.
